# OmpDesk 差异化改造计划(对标 pi-desktop / Codex 桌面端)

## 定位与目标
把 OmpDesk 从"单 agent 聊天 GUI"升级为**深度 Agent 工作台**:多语言、桌面级菜单与设置、产出可视化(文件面板)、过程透明化(token 汇总)、双后端(omp + pi)。参照对象:pi-desktop(文件面板/会话体验)、OpenAI Codex 桌面端(菜单/设置结构/快捷键)、Claude Desktop(对话深度)。

**实施前提(重要):等待 `sess_d7476a8c`(UI 迁移会话)全部完成并提交后再开工** —— 重叠文件多(SettingsModal / Sidebar / Composer / MessageBubble / store.ts / global.css),双会话并发会互相覆盖。开工第一步用 codex-vision.sh 精读你的 5 张 Codex 截图(已找到 1 张 `Downloads/1781628871703.png`,其余 4 张需你提供路径或重发),对齐菜单/设置细节。
